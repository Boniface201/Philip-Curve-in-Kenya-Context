# Kenya Phillips Curve Dashboard (2000–2023)

This Power BI project analyzes the relationship between **inflation** and **unemployment** in Kenya over the period 2000–2023 to visualize the Phillips Curve.

## 📊 Dashboard Preview
![Dashboard Screenshot](dashboard_preview.png)

## 🔍 Key Insights
- **2008 Inflation Spike** correlates with post-election violence.
- **COVID-19 years** show atypical inflation-unemployment dynamics.
- Weak long-term inverse relationship between the two variables.
